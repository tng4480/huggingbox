## Model Lab

- Fine-tune supported language models with LoRA using MLX on Apple Silicon or PyTorch on CPU/NVIDIA.
- Train text and image classifiers with head-only or full-model fine-tuning. Import labelled JSONL or image class folders.
- Validate datasets, reject duplicates, preserve separate train/validation/test splits, and keep original weights unchanged.
- Compare held-out predictions before and after training. Classifiers report accuracy, macro F1, per-class metrics and confusion matrices.
- Track training, cancel jobs, retain run history and recover readable language-model adapter checkpoints with a fresh optimizer.
- Export adapters or complete classifiers, including preprocessing and label mappings.

## Model inspection

Explore ordinary and Jacobian-lens readouts in an interactive layer/token view. Fit exploratory checkpoint-specific lenses and compare original/adapted language-model readouts. Model and lens checksums guard against incompatible artifacts.

## Verification and limitations

44 automated tests passed on macOS, alongside native app checks, real Qwen training/evaluation/inspection, and synthetic BERT/ViT classifier training and export/reload checks. The Windows release workflow also runs the applicable regression tests before building installers.

J-lens readouts are exploratory vocabulary associations, not thoughts or causal explanations. A base-model lens transferred to a fine-tuned model is unvalidated. MLX adapters are not automatically converted for PyTorch inspection. Classification is single-label; classification continuation is not yet supported. Language-model continuation restores adapter weights, not optimizer/RNG state.

Speech, embedding and diffusion training are not implemented. Windows/CUDA training and large-model memory behavior remain unverified. Start with small supported models. CLI assistant integrations from v0.2.0 remain available.
